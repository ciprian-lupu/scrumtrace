## Part B, Close the loop

Shortest path from today to a recorded Gate 0 and Gate 1 pass on one Mac. Task zero is the signing identity: `scripts/ensure_debug_signing_identity.sh` cannot produce a trusted identity as written (TCC-1), and `scripts/mac_gate01.sh:57-62` swallows that and ad-hoc signs (`:69`), so every rebuild has been a new TCC client. Until B.2 below shows `Authority=ScrumTrace Debug` and a certificate-anchored designated requirement, nothing else in this plan is testable.

### B.1 Task zero, the identity

Apply TASK-01 first (Part E) so the script itself produces a trusted identity. If Gate 0 must be attempted before TASK-01 lands, the manual equivalent is:

```bash
bash scripts/ensure_debug_signing_identity.sh; echo "exit=$?"
security find-identity -p codesigning    | grep -F "ScrumTrace Debug"   # untrusted identities appear here
security find-identity -v -p codesigning | grep -F "ScrumTrace Debug"   # only valid ones; the script needs this line

# If the second grep is empty (expected per TCC-1): trust the certificate once. One GUI password prompt.
P12="$HOME/Library/Application Support/ScrumTrace/signing/ScrumTrace-Debug.p12"
/usr/bin/openssl pkcs12 -in "$P12" -clcerts -nokeys -passin pass:scrumtrace-debug -out "$TMPDIR/scrumtrace-debug.pem" 2>/dev/null \
  || openssl pkcs12 -legacy -in "$P12" -clcerts -nokeys -passin pass:scrumtrace-debug -out "$TMPDIR/scrumtrace-debug.pem"
security add-trusted-cert -p codeSign -k ~/Library/Keychains/login.keychain-db "$TMPDIR/scrumtrace-debug.pem"
security find-identity -v -p codesigning | grep -F "ScrumTrace Debug"   # PASS: exactly one line
```

If `security import` reported "MAC verification failed" the p12 was exported by Homebrew OpenSSL 3 (`which openssl`); re-run the script with `PATH=/usr/bin:$PATH` so LibreSSL exports a p12 macOS accepts. If `add-trusted-cert` refuses without `-d`, use Keychain Access, double-click the certificate, Trust, Code Signing: Always Trust.
