# ScrumTrace

Mac menu-bar meeting and QA context recorder: captures presentation screen and audio with zero drift, then writes `AGENT_CONTEXT.md`, `SESSION_BRIEF.html`, and a lightweight session pack (< 35 MB) to drop directly into Cursor, Claude Code, or any AI coding assistant.

- **Shot (`Opt+Cmd+S`)**: Grabs screenshot and opens instant note window (draw box/arrow/pen, type, or hold-to-talk voice note).
- **Pin (`Opt+Cmd+Space`)**: High-priority timeline bookmark without interrupting presentation.
- **Pause (`Opt+Cmd+P`)**: Instant pause with zero audio/video persistence (auto-pauses on credential managers).
- **Status:** Audited production specification in [IMPLEMENTATION_PLAN.md](IMPLEMENTATION_PLAN.md). App not built yet.
